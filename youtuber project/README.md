# Whac-A-Mole Game

## Overview
This project is a Mario-themed **Whac-A-Mole** game built using **HTML5 Canvas**, **CSS**, and **JavaScript**. The game involves whacking moles and piranha plants as they randomly appear on the game board.

### Links
- **Coding Tutorial**: [Watch on YouTube](https://youtu.be/ej8SatOj3V4)
- **Live Demo**: [Play the Game](https://imkennyyip.github.io/whac-a-mole/)

---

## Features
- **Dynamic Game Board**: The game board is dynamically created and managed using JavaScript and DOM manipulation.
- **Randomized Spawning**: Moles and piranha plants appear randomly on the board, increasing the challenge.
- **Interactive Gameplay**: Players can "whack" the moles by clicking on them, earning points.
- **Mario Theme**: The game features a Mario-inspired design for an engaging experience.

---

## Learning Objectives
By following this project, you will learn:
1. How to use **HTML5 Canvas** for game development.
2. How to manipulate DOM elements with **JavaScript**.
3. How to add **event listeners** for interactive gameplay.
4. Techniques for **randomized spawning** of game elements.
5. Styling and layout using **CSS**.
